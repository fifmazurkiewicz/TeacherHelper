# Shared skills and workflows

Global skills: `using-superpowers`, `brainstorming`, `writing-plans`, `writing-skills`, `design-taste-frontend`, `ux-ui-challenger`, `fastapi`, `ponytail`, `ponytail-review`, `diagram-design`, `web-quality-audit`, `web-performance`, `core-web-vitals`, `web-accessibility`, `web-seo`, and `web-best-practices`.

Workflow requirements are defined in `AGENT_STANDARD.md`. Ponytail is a mandatory review ladder; `ponytail-review` is installed as a skill without lifecycle hooks. Hooks are intentionally not enabled.

Before creating a project from this template, replace this file only if the required skills differ and document the reason.
