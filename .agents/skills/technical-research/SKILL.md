# Technical Research

Read `frame.md`, project documentation, and relevant Graft knowledge; if Graft
is unavailable, use focused `rg` and say so. Create `research.md` containing
verified repository facts, relevant external facts with source and date,
unknowns, constraints, and alternatives.

Keep observations separate from decisions. Do not choose an approach, alter
code, or manufacture evidence. Record a fact only when it can be traced to a
source, command result, or clearly labeled assumption. Hand off to decisions
and planning.
